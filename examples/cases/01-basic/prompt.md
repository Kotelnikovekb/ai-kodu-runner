# Задача для AI-агента

## Контекст

Опиши здесь проект, его архитектуру и важные ограничения.

## Что нужно сделать

Опиши конкретную задачу:

- какой функционал реализовать или исправить;
- какие файлы можно изменять;
- какие файлы изменять нельзя;
- какие пользовательские сценарии должны работать.

## Критерии готовности

- [ ] Код собирается.
- [ ] Существующие тесты проходят.
- [ ] Добавлены тесты для нового поведения.
- [ ] Нет commit или push.

## Проверки

Запусти необходимые команды и исправь найденные ошибки:

```text
# например:
# flutter analyze
# flutter test
# npm test
```

## Результат

В финальном ответе укажи:

1. Что изменено.
2. Какие проверки выполнены.
3. Какие проблемы остались.
