# Code of Conduct

Участники проекта обязуются поддерживать уважительную, профессиональную и
инклюзивную среду.

Недопустимы harassment, дискриминация, угрозы, публикация чужих личных данных,
троллинг и намеренное нарушение работы проекта.

Сообщить о нарушении можно владельцу репозитория приватным сообщением. Все
сообщения будут рассмотрены конфиденциально и добросовестно.
