# runner-protocol

Public versioned JobSpec, JobResult, execution requirements and failure
protocol for [AI Kodu Runner](https://github.com/Kotelnikovekb/ai-kodu-runner).

The wire compatibility policy is documented in the repository's
[`docs/VERSIONING.md`](https://github.com/Kotelnikovekb/ai-kodu-runner/blob/main/docs/VERSIONING.md).
